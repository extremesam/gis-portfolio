# Lagos Population Density Map

## Objective
To visualize population distribution across Lagos using raster population data.

## Status
🚧 In Progress

## Data (Planned)
- WorldPop raster data
- Lagos administrative boundary (GeoJSON)

## Method (Planned)
1. Load raster into QGIS
2. Clip to Lagos boundary
3. Classify population density
4. Produce choropleth map
